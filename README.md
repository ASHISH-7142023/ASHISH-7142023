### Hey there! I'm Ashish Ranjan Singh 👋

I am a passionate **Full-Stack & Software Engineer** dedicated to building premium, high-fidelity user interfaces and horizontally-scalable backend architectures. I specialize in merging high-fidelity visual design (such as glassmorphism, custom SVG forecasting charts, and smooth keyframe animations) with production-grade backend networks (Java/Spring Boot, Node.js/Express, Redis, and relational databases).

* **🔭 Working on:** Scalable real-time synchronization systems and interactive AI dashboards.
* **🎨 Design Philosophy:** Minimalist layouts, HSL-curated color schemes, fluid transitions, and rich micro-interactions.
* **⚡ Fun Fact:** I love recreating complex animations and interactive tools (like credit engines and physics timelines) directly in vanilla CSS & SVG.

### 🛠️ Featured Projects

Here are a few notable projects I've built, reflecting my focus on performance, system architecture, and aesthetic visual design:

#### 1. 🌌 [SyncStream](https://github.com/ASHISH-7142023/SyncStream)
* **High-Level Goal:** Production-grade, horizontally-scalable real-time room chat application.
* **Stack:** `React SPA` | `Spring Boot` | `Redis Pub/Sub` | `STOMP WebSockets`
* **Key Features:** Multi-server backend cluster synchronized in real-time. Features a glassmorphic design system using HSL-curated color tones, custom typography, dynamic spring animations, and automatic connection recovery.

#### 2. 📈 [FinSphere AI](https://github.com/ASHISH-7142023/FinSphere-AI)
* **High-Level Goal:** Premium, cinematic personal finance super-app MVP with interactive AI calculators.
* **Stack:** `HTML5` | `Vanilla CSS3` | `ES6 JavaScript` | `SVGs`
* **Key Features:** Dynamic SVG Bezier forecasting timeline (scaling to 10-year plans), and a custom Credit Score Engine with dynamic sliders and SVG scoring gauges. 

#### 3. 🍰 [Singh Cake Delight](https://github.com/ASHISH-7142023/SINGH-CAKE-DELIGHT)
* **High-Level Goal:** Elegant full-stack cake-ordering storefront with admin configuration tools.
* **Stack:** `React 18` | `TypeScript` | `Express 5` | `PostgreSQL` | `Drizzle ORM` | `Tailwind CSS`
* **Key Features:** Soft Cream & Warm Bakery custom layout palette. Features transactional database synchronization, responsive calendars for order scheduling, and direct WhatsApp api messaging.

#### 4. 🛍️ [Prime Pick](https://github.com/ASHISH-7142023/PRIME-PICK)
* **High-Level Goal:** Clean, responsive multi-page e-commerce template for fashion garments.
* **Stack:** `HTML5` | `Vanilla CSS3` | `jQuery` | `Remix Icons`
* **Key Features:** Local product search, dynamic local-storage shopping cart cloning, keyframe animations on hover state, and a custom mouse cursor-tracking circle overlay.
